# Web UI

## 目标

生成用于用户确认页面结构、视觉风格、交互流程和关键状态的 Web UI，并为 Android UI 实现提供参考。

## 输入

参考页面目标、用户角色、信息架构、内容、操作与交互、默认/加载/空/错误/禁用/反馈状态、视觉风格、适配要求，以及需对齐的既有 UI 风格。缺少非关键细节时，采用合理默认假设，并在 `ui-spec.md` 记录。

## 流程

1. 梳理 UI 需求并形成 UI 规格。
2. 设计组件层级、布局、交互与状态。
3. 生成可预览 UI，优先单文件 `index.html`，包括必要的 HTML、CSS 和轻量 JavaScript。
4. 保存至 `ui/<需求名>/`，无需在生成前单独等待确认。
5. 记录默认假设，供需求管理流程展示和迭代。

## 输出

至少创建：

- `ui/<需求名>/index.html`
- `ui/<需求名>/ui-spec.md`

`ui-spec.md` 要覆盖 UI 目标、页面结构、组件、交互、状态、视觉风格、关键假设和 Android 实现参考。页面必须层级清晰、主操作突出、适合移动端映射，并避免不可控外部依赖。
