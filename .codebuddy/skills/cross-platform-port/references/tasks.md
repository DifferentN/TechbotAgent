# 校验工具实现计划

本文件仅记录本 Skill 配套校验器的实现步骤，不是业务迁移的授权或任务计划。

## Task 1：配置、规格与设计静态闸门

- Step 1.1：先写 `tests/test_validate_port.py`。覆盖有效草稿、双向 ready、真实路径隔离、符号链接越界、未知关键字、引用/ID、契约/状态/场景覆盖、批准摘要失效、设计绑定与文件白名单。运行 unittest，确认因校验器尚未实现而失败。
- Step 1.2：创建两个配套 JSON Schema、合成样例、`scripts/validate_port.py`。只读校验，拒绝不完整/越界/未知结构；ready 必须验证摘要、目标写入许可和高风险项。运行测试直至全部通过。
- Step 1.3：检查可维护性和重复逻辑，必要时重构并重复全部测试；对双副本做内容一致性检查与打包。不提交 Git，除非用户另行要求。

## 验收

Python 3.11+、零第三方运行依赖；不执行配置命令、不修改业务代码、不伪造真实授权。摘要绑定检查只用于防止产物变更，不能认证用户消息或代替沙箱。默认空配置必须拒绝；合成样例不得被声明为真实迁移证明。
